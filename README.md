# Complexify

**Complexify** adalah platform pembelajaran interaktif untuk memahami **bilangan kompleks** dengan cara yang lebih mudah, visual, dan menyenangkan. Proyek ini dibuat sebagai tugas UAS mata kuliah Kalkulus I.

## Akses Website

Kunjungi langsung: [complexify-10.vercel.app](https://complexify-10.vercel.app)

## Fitur Utama

- **Materi Belajar** – Penjelasan lengkap dan terstruktur dari definisi dasar bilangan kompleks hingga Transformasi Fourier, dilengkapi ilustrasi visual.
- **Game Tebak Koordinat** – Uji pemahaman Anda dengan menebak posisi titik pada bidang kompleks. Belajar sambil bermain!
- **Kuis Interaktif** – Soal-soal adaptif yang mengasah pemahaman materi secara bertahap.
- **Profil Tim** – Kenali para pembuat Complexify.

## Teknologi yang Digunakan

- **Hosting** – Vercel
- **Bahasa Pemrograman** – JavaScript (ES6+)
- **UI** – CSS
